ROYAL ROSE - NEW TEMPLATE BRIEF
================================

Scop
----
Vreau un nou template de invitatie, bazat pe fluxul si datele din "Royal Rose",
dar cu alt design vizual.

Important:
- logica trebuie sa ramana compatibila cu proiectul actual
- nu se schimba modelul de date
- nu se schimba block types
- nu se schimba prop-urile principale
- schimbam doar UI, layout, animatii, decoratiuni, compozitie si stil

Ce trebuie sa inteleaga Claude
------------------------------
Noul template trebuie sa functioneze exact ca Royal Rose la nivel de date si editare:

- primeste "data"
- foloseste "data.profile"
- foloseste "customSections"
- foloseste aceleasi block types
- poate deschide RSVP cu "onOpenRSVP"
- poate actualiza profilul prin "onProfileUpdate"
- poate actualiza blocurile prin "onBlocksUpdate"

Pe scurt:
aceeasi logica, alt design.


Contractul pe care NU are voie sa il schimbe
--------------------------------------------
1. Wrapper simplu de forma:
   - componenta wrapper care primeste SimpleTemplateRenderProps
   - pasa data mai departe catre componenta full
   - converteste onBlocksUpdate in customSections JSON

2. Componenta full trebuie sa ramana compatibila cu:
   - InvitationTemplateProps
   - InvitationBlock
   - UserProfile

3. Trebuie sa existe:
   - export const meta
   - export const CASTLE_DEFAULTS
   - export const CASTLE_DEFAULT_BLOCKS
   - export const CASTLE_PREVIEW_DATA
   - export default pentru componenta principala

4. Trebuie sa foloseasca aceeasi idee de tema:
   - colorTheme din profile
   - palete compatibile cu registry-ul actual
